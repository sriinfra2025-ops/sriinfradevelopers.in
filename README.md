## Before launch
Replace placeholder phone, email, office address, project names/locations and project images with verified business information. Configure the enquiry form with your preferred email service or WhatsApp business number.

## Hosting
This is a static site and can be hosted free on GitHub Pages. The GoDaddy domain can be connected as a custom domain.
